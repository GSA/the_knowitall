# Project

The Knowitall owns revision-bound code context through `knowitall.code-context/v1`.
Native Kata project is `the_knowitall`; repository `.kata.toml` binds it.

Local Python packages compose immutable admitted snapshots, pinned deterministic
Graphify, durable update requests, atomic publication and qualified queries.
Graphify owns parsing and incremental graph reconciliation. Updates use a private
stable workspace and restore only validated graph/manifest checkpoints.

Approved verification uses synthetic repositories only. Source acquisition,
source execution, model routes, production runtime attestation and hosted services
require their own authorization. Retained source/graphs stay outside Git.
